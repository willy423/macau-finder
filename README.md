# 마카오 리조트 매장 찾기

마카오 리조트(베네시안 등)의 매장·식당·편의시설 위치를 검색하고 층별 지도를 보는 개인 응대용 페이지입니다.

## 구조
- `index.html` — 화면 (수정할 일 거의 없음)
- `data/resorts.json` — 리조트 목록과 지도 파일 경로
- `data/<리조트>.json` — 리조트별 매장·식당·시설 데이터
- `maps/` — 층별 평면도 이미지

## 리조트 추가 방법
1. `data/<id>.json` 파일 추가 (venetian.json과 같은 형식)
2. 평면도 이미지를 `maps/`에 추가
3. `data/resorts.json`에 항목 추가

## 출처
- 매장·식당·부대시설: 각 리조트 공식 사이트 (베네시안: venetianmacao.com, 2026-10-12 수집)
- 중국어(번체)명: 공식 홍콩판 사이트 (hk.venetianmacao.com)
- 평면도: 리조트 제작 평면도 (저작권은 각 리조트에 있음)
- 한글명은 통용 표기(참고용), ATM 위치는 평면도 아이콘 기준 추정
